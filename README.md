## Getting Started

1. Clone this repository
2. Navigate to the lesson folder you want to study
3. Read the README.md in each lesson folder
4. Review the example code in the `examples/` folder
5. Complete the exercises in the `exercises/` folder

## Prerequisites

- Basic understanding of JavaScript
- Familiarity with Node.js
- Understanding of HTTP protocols
